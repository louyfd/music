构建命令：powershell -ExecutionPolicy Bypass -File tools\build_with_cst.ps1 -Mode release
生效约束：src\music_release.cst（实装版；music.cst 调试版被置为 enable=0）

--------------------------------------------------------------------------------
0. 一句话
--------------------------------------------------------------------------------
RTL 与 V49.2_共享波表 **完全相同**，只把引脚约束从调试版换成实装版重跑一遍。
换约束会改变 IO 位置 → 布线结果变 → **必须重新判三处时序**（本次已判，见 §2）。

--------------------------------------------------------------------------------
2. ★ 时序三处判定（本版实测，别套用调试版的数字）
--------------------------------------------------------------------------------
[1] TNS 汇总表：**六个 0.000**（clk_50m / CLKOUT0 / CLKOUT1 的 Setup+Hold），违例端点 **0 / 0**
[2] 最差 setup：**+0.328 ns**（u_uart_packet_echo/rel_us_r）
[3] 最差 hold ：**+0.001 ns**（gen_ks[9].u_ks 的 RAM 写地址路径 —— 与 V48.5/V49/V49.1/V49.2 同性质，历来如此）
Fmax：clk_50m 50→**82.173** / CLKOUT0（音频域）12.5→**25.063** / CLKOUT1 50→**50.833 MHz**（约束 50，余量 1.7%）
构建标志：RUN_OK = 1，RUN_ERR / PR0004 / DesRoute = **0**

--------------------------------------------------------------------------------
3. 资源（与调试版逐项一致 → 换引脚约束不引入额外逻辑）
--------------------------------------------------------------------------------
Logic 42462/59904（71%）、Register 15661、CLS 25130/29952（**84%**）、BSRAM 87/118、DSP 56.5/118、I/O Port 28/297
★ CLS 84% 是 V49.2 共享波表换来的余量（V49.1 曾到 89%，90% 那版直接布不通）；本版仍属"可布通但不宜再加逻辑"的区间。

--------------------------------------------------------------------------------
4. 功能口径（与 V49.2 相同）
--------------------------------------------------------------------------------
36 键位 × 97,656.25 Hz = 3,515,625 样本/秒；含 8 路测试声部共 **44 路 = 4,296,875 样本/秒**。
含：采样率翻倍（V49）、测试模式 44 路（V49.1）、共享波表（V49.2）、LCD 看门狗 0.8s/1.0s 修复（`lcd_master.v` = D15482BF…）。

--------------------------------------------------------------------------------
5. 上板验证清单（本版是给真板子烧的，请逐条确认）
--------------------------------------------------------------------------------
① 按「重置LCD」→ 黑约 1.0 s → 重新初始化 → 全屏清 → **谱线逐列回来**（不该再卡）
② 板子第 11 键（按钮板）进测试模式 → 听到密集和弦（44 路）；**LCD 上只有 36 根柱是设计如此**，
   那 8 路排在 A5 880Hz~E6 1319Hz，要用【音频输出频谱】（示波器 FFT / 频谱软件）数峰
③ APP 的「测试模式」按钮与板载第 11 键**双向同步**
④ 听感与画面：八度 / 吉他音准与衰减 / 混响尾巴长度 / 波形屏时间基 均与 V48 一致
⑤ V44 延迟测量脉冲：宽度 2 µs，两段分得开
⑥ 退出测试模式后：音色、效果、延音**逐位还原**
