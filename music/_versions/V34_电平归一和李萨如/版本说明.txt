V34 —— 多声部电平归一 + 李萨如图形
========================================================================

一、多声部电平归一（治"同时响多个音就不干净"）
------------------------------------------------------------------------
【问题】混音级原来是 `mix = mix_pre >>> 1`（一个【固定】右移），之后只乘
        一个【全局】音量。于是总电平随"在响的声部数"线性涨：按原标定约
        4 个声部满包络就到满幅，再多就顶穿 16 位输出（削顶/回绕）。
        听感 = 两个音以上发糊、不干净，低音一强音高还发飘。
        ★ 这和"是不是和弦"无关：只要同时响的音多于一个就会犯。

【修法】按在响声部数给 headroom，系数取 1/sqrt(N) 那一档：
            N=1 -> 256(×1.00)   N=2 -> 192(×0.75)  N=3 -> 154(×0.60)
            N=4 -> 128(×0.50)   N=5 -> 115         N=6 -> 102
            N>=7 -> 90          （分母 512）
        ★★ N=1 时 256/512 = 1/2，和原来的 `>>> 1` 【逐位相同】★★
           也就是说：单音、以及只有一个声部在响的曲子，输出一个采样点
           都不会变 —— 原来正常的听感原样保留（用户反复强调的那条）。
        实现：36 位 popcount（加法树，不占 DSP）+ 一张 7 档表 +
              一个 24×9 乘法器（占 1 个 DSP）。
        为什么不用限幅了事：限幅只是把超出部分砍掉，音多时照样糊；
        先按声部数把电平让开，才能让任何声部数都落在量程内。
        代价实测：Logic 36,590 -> 36,633（+43）、Register +118、DSP +1。

二、李萨如图形（按键 3 三档循环：频谱 -> 波形 -> 李萨如）
------------------------------------------------------------------------
【接法】top.v 新增 disp_mode[1:0]，按键 3 按一下加一循环；
        wave_mode = (disp_mode==1)、liss_on = (disp_mode==2) 送给 lcd_master，
        ★ wave_mode 的原语义一个字没变（只是现在由 disp_mode 派生）。
【显示】lcd_master 新增：320×240 显存（2 bit/像素 = 4 档绿，9 块 BSRAM）、
        打点、余辉衰减（每 LISS_DECAY_DIV 帧减一档）、边框 + 中心十字，
        ★ 余辉衰减和推屏挤在【同一遍扫描】里（显存是单读单写的 BSRAM，
          一帧 76800 个像素，推的时候顺便写回 max(0,px-1)，省一遍访问）。
        ★ 只有 liss_on=1 才走这条通路；liss_on=0 时新加的寄存器全部原地不动
          —— 频谱/波形那两屏的状态机、常数、刷新节奏一个字都没动。
【两路信号】X = 干声（混音后、进效果前），Y = 效果后的输出。
        不开效果是对角线，开延迟/混响/合唱会张开成环或螺旋。
        实现细节见 lcd_master.v 里 LISS_* 那几个 localparam（想调余辉长短、
        亮度、十字位置就改它们）。
【谁写的】这一块是另一个代理按我给它的规格实现的，它在中途被停、没交报告，
        所以【我逐段审过】：模式循环、liss_on 优先、老两屏不受影响、
        显存/推屏/余辉的结构与常数都对得上设计。它综合通过、时序 0 违例、
        契约检查全过 —— 但★【实际画出来好不好看、形状对不对，只能上板子看】，
        这一条我在这里如实标注为"未经验证"。

四、怎么用 / 要你验的
------------------------------------------------------------------------
【烧录】_versions\V34_电平归一和李萨如\bitstream\music.fs
【听】放一首多声部的（有和弦/伴奏的）—— 应该比以前干净、不再发糊；
      单音的曲子听感应该和以前【完全一样】（这条是设计保证）。
【看】按键 3 循环：频谱 -> 波形 -> 李萨如。李萨如是绿色点阵 + 余辉，
      中间有十字、四周有边框。不开效果时应该是【一条斜线】，
      开延迟/混响/合唱后应该张开成环或螺旋。
      ★ 如果形状明显不对（比如乱点、只有一条边、闪得厉害），
        告诉我"哪一屏、什么现象"，我按 LISS_* 那几个常数调。
【配合】软件那边这次没改，电脑版/安卓不用换。
