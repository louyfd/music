================================================================================
V49_采样率翻倍 版本说明 —— 输出采样率 48.828 → 97.656 kHz（吞吐量 ×2），
                          功能与效果【逐项不变】
================================================================================
归档时间：2026-10-12
构建命令：powershell -ExecutionPolicy Bypass -File tools\build_with_cst.ps1 -Mode debug

--------------------------------------------------------------------------------
0. 一句话
--------------------------------------------------------------------------------
把 I2S 帧从 256 拍压到 128 拍（`BCLK_HALF` 2→1），输出采样率翻倍到 97.656 kHz。
**不改 PLL、不改时钟树、几乎不花资源**（Logic 47058→47018、CLS 25329→25319、
BSRAM 87→**87**），系统吞吐量由 1,757,812.5 升到 **3,515,625 样本/秒**。

★★ 关键设计（这一版真正的难点）：采样率翻倍会让**所有"按采样点计时"的东西快一倍**
   ——包络衰减时间减半、滑音快一倍、颤音/合唱/延迟/混响全部减半、LCD 电平扫描快一倍。
   所以新增【控制节拍 `ctrl_en`】（每 2 个采样点 1 拍 = 48.828 kHz 等效），
   把"时间语义"逻辑全部挂上去，**让这些量的时间常数逐位不变**；
   而"内容类"逻辑（相位累加、波表读相位、逐键包络乘法、KS 弦）继续全速 97.656 kHz。

--------------------------------------------------------------------------------
1. 用户要求（本版的验收标准）
--------------------------------------------------------------------------------
原话：「**要尽量保证全部正常的功能效果不变**」。
所以本版的目标不是"改出新功能"，而是**在指标翻倍的同时，把所有已验收的效果原样保住**。
第 4 节是不变性审计的逐项结论。

--------------------------------------------------------------------------------
2. 逐条改动（全部在 top.v 内，另有 tools\ks_model.py 与测试脚本）
--------------------------------------------------------------------------------
(d1) I2S 参数：`BCLK_HALF = I2S_SPEC ? 1 : 3`
     → `FRAME_DIV` = 64×1×2 = **128**、`SAMPLE_RATE_HZ` = 12.5M/128 = **97656**、
       `SAMPLE_CNT_MAX` = **127**；BCK 3.125 → **6.25 MHz**（BCK/fs 仍是 **64×**）
     ★ 这是本版唯一影响声音的改动，也正是指标提升的来源。

(d2) 新增 `ctrl_ph` / `ctrl_en`：`ctrl_ph` 每个 `sample_en` 翻转一次，
     `ctrl_en = sample_en && ctrl_ph` → 每 2 个采样点 1 拍，**相位确定可复现**。

(d3) 16 处"时间语义"逻辑 `sample_en` → `ctrl_en`：
     包络起音计数/包络推进/门控计数、滑音斜坡、增益斜坡（AGC）、颤音 LFO、
     合唱填充与 LFO 与写入、延迟填充与写入、混响写入、Haas 写入、
     LCD 电平扫描、TEST_SINE 相位。

(d4) **拆开一处混用块**（本版最容易搞错的地方）：原来滑音斜坡与相位累加共用
     一个 `if (sample_en)`。现在滑音走 `ctrl_en`（时间），相位累加留在
     `sample_en`（内容）——否则音高会正好掉一个八度。

(d5) 送显锁存加 `ctrl_ph`：`ph_x1/ph_y1` 与 `wave_send/.../wave_tgl` 两块
     **用字符串完全相同的判据**，使 LCD 收到的点速率仍是 48.828 kHz、
     波形屏时间窗与李萨如图形密度与 V48 **逐点一致**。

(d6) KS 弦（吉他音色）：延迟线 512 → **1024 格**（`ptr/raddr/waddr` 9→10 位），
     并用 `tools\ks_model.py`（FS 改为 12.5M/128）**重新生成 NI/FR/DMP 三张表**。
     ★ 96 kHz 下最低音 A2 需要 **888** 格（48 kHz 时是 444），512 格装不下；
       而 **1024×16 = 16 Kbit 仍然只占 1 块 SDPB（18 Kbit）**
       → 加深延迟线【没有多花一块 BSRAM】（实测归档资源表 BSRAM 仍 87）。

(d7) V44 延迟测量脉冲宽度 10 µs → **2 µs**：帧周期由 20.48 µs 减半到 10.24 µs，
     10 µs 脉冲会顶到下一个事件、两路糊在一起。2 µs ≪ 5.12 µs（半帧）✓
     （该功能仍然可用，且两段比原来更容易分开。）

(d8) 注释同步：I2S 参数说明、KS 弦头注释、"每 288/256 拍"等旧数字全部更新，
     并明确标出哪些 48828 Hz 的说法**仍然成立**（因为那些逻辑现在挂 ctrl_en）。

--------------------------------------------------------------------------------
3. 为什么合法（PCM5102A 手册 ZHCS323B，资料\MRG5102A-GY-PCM5102+资料\pcm5102.pdf）
--------------------------------------------------------------------------------
· 采样率支持 **8 kHz ~ 384 kHz** → 97.656 kHz 在范围内；
· 系统时钟倍率表含 **64**（本板 SCK 接 GND，DAC 拿 BCK 当系统时钟）→ 比值 64× 合法；
· 系统时钟最高 **50 MHz** → BCK 6.25 MHz 远低于上限；
· **不改 PLL 红线**：`clk_audio` 仍是 12.5 MHz，只是每帧占的拍数减半。

4. ★★ 功能与效果不变性审计（逐项，全部有出处）★★
--------------------------------------------------------------------------------
| # | 功能 | 结论 | 依据 |
|---|---|---|---|
| 1 | **音高（36 键）** | **不变** | `SAMPLE_RATE_HZ` 与 `calc_delta()` 都是常数推导，36 个频率字自动跟随；sim 逐键复算相对误差 < 0.05% |
| 2 | **包络（ADSR 起音/衰减/释音）** | **逐位不变** | 全部计数挂在 ctrl_en，节拍率仍是 48828.125 Hz、常数未改 |
| 3 | **释音去抖 8 ms** | **不变** | `gate_off_cnt` 的 1 ms 慢拍来自 ctrl_en 块内的 `gate_tick_cnt` |
| 4 | **滑音（Portamento）** | **不变** | `GLIDE_STEP` 未改，斜坡走 ctrl_en |
| 5 | **颤音 / 合唱 / 延迟 / 混响 / Haas** | **时间常数不变** | 抽头常数未改（RVB 1024/1429/1663 = 21.0/29.3/34.1 ms、HAAS 732 = 15.0 ms），推进走 ctrl_en；LFO 相位轨迹不变 |
| 6 | **AGC / 声部避让** | **不变** | 增益斜坡走 ctrl_en；`voice_scale` 表未改 |
| 7 | **吉他音色** | **音准与衰减不变** | 按新 fs 重算 NI/FR；damp 分组与 V48 完全一致（≤400 Hz 用 6，其余 7）→ 每圈损耗相同、绕圈时间相同 → T60 不变；实测 36 键最大偏差 **0.28 音分** |
| 8 | **LCD 波形 / 李萨如** | **逐点一致** | 送显判据加 ctrl_ph，点速率仍 48.828 kHz；两块判据字符串相同（有检查盯着） |
| 9 | **LCD 频谱柱（每键电平）** | **逐位不变** | `scan_val <= env[...]` 走 ctrl_en，与包络同拍同值 |
| 10 | **录音回传** | **不变** | 采样节拍是 clk_50m_ext 域的 `REC_TICK_DIV = 500_000`（10 ms），与音频域无关 |
| 11 | **节拍器 / LED / 播放指引** | **不变** | 节拍器与 LED 都在 clk_50m 域；`led_guide.v` 用自己的 `CLK_HZ=12_500_000` 计时，不引用 sample_en/FRAME_DIV |
| 12 | **LCD 看门狗 / 手动重置（V48.4/V48.5）** | **不变** | 都在 clk_50m_ext 域，计时器是 50 MHz 计数，与音频域无关 |
| 13 | **协议 / 蓝牙 / 上位机** | **不变** | 帧格式、字节率、上报时机都没动；上位机一个字都不用改（尾巴常数仍按 48828 Hz 标定，见 §5） |
| 14 | **移调 / 逐键八度 / 音色 / 效果开关 / 延音** | **不变** | 纯逻辑，无采样率依赖 |
| 15 | **立体声 / 左右声道分离** | **位对齐不变** | I2S 位级仿真（stereo_check 55 项）在**新参数下**重新解帧，两个槽的样本逐位正确 |
| 16 | **延迟测量脉冲（V44）** | **宽度 10µs→2µs（必要调整）** | 帧周期减半，见 (d7)；功能仍可用且两段更易分开 |

★ 结论：**除"输出采样率翻倍"这一项（本版的目的）与脉冲宽度这一项（帧周期减半的
  必然结果）之外，其余 14 项功能/效果的时间常数与数值轨迹全部保持不变。**

唯一需要如实说明的差异：效果器的**湿声**支路现在是在 97.656 kHz 上做零阶保持
（每 20.5 µs 更新一次，因为它按 ctrl_en 推进），干声与振荡器仍是全速 97.656 kHz。
湿声本身的内容带宽与 V48 一致（仍受延迟线速率限制），听感无变化。

7. 回退
--------------------------------------------------------------------------------
`BCLK_HALF` 改回 `I2S_SPEC ? 2 : 3`、删掉 ctrl_en 并把 16 处改回 sample_en、
KS 表改回 512 格版本（`_versions\V48.5_手动重置LCD\` 里有），即可回到 V48.5。
★ 不要只改 BCLK_HALF 而不动 ctrl_en —— 那会让所有时间常数减半。
