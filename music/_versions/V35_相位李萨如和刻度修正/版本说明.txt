V35 —— 相位式李萨如（按键 3 第三档）+ X/Y 刻度修正
========================================================================

一、这一版做了什么
------------------------------------------------------------------------
按键 3 的循环从三档扩成四档：

    频谱 → 波形 → 李萨如(干声 × 效果后) → 李萨如(相位) → 循环

【档 3 = 相位式李萨如】
  X = 最终输出 sample_vol
  Y = sample_vol 经过【一级一阶全通移相】（302Hz 处正好 −90°）
  于是：中音区单音画成【接近正圆】的闭环，低音/高音是扁环，
        和弦/吉他会变成多环叠加的"花环"（X-Y 示波器的正常表现）。

【移相器系数】（★ 这里差点写错，记下来）
  递归 y[n] = a*x[n] + x[n-1] - a*y[n-1] 的极点在 z = -a，
  所以 a 必须取【负号】：a = -0.96185（Q15 = -31518/32768）→ 极点 +0.96185 → f90 = 302Hz。
  若取 a = +0.96185，极点落到 -0.96185 → f90 = 24.1kHz，带内相移只有 0.04°~2°，
  图形还是那条对角线（等于白做）。
  精确解 f90 = SR/4 - (SR/π)·atan(|a|)，与近似式差 0.03%。
  实现整理成 1 个乘法器：y = a*(x[n] - y[n-1]) + x[n-1]（占 1 个 DSP）。

  实测相移（SR = 12.5MHz/256 = 48828Hz，Q15 量化后）：
      110Hz -40.0° ｜ 220Hz -72.1° ｜ 302Hz -90° ｜ 440Hz -111.1° ｜ 830Hz -140.0°
  偏离 90° 最大 50°（两端对称）—— 一级全通在 3 个八度内的固有代价。
  ★ 为什么不做两级：穷举证明两级反而更差（相移跨度只多 5°、偏差更大），
    而且两级容易在带内撞到 180° 整数倍 —— 那一刻两轴反相、图形【退化成直线】。

【★ X/Y 刻度修正（治"圆不圆"）】
  原来映射是 col = 160 + (X×140)>>15、row = 120 - (Y×100)>>15 ——
  X 满量程 ±140 像素、Y 只有 ±100，于是信号空间里的正圆在屏上被压成
  短/长轴 100/140 = 0.714 的椭圆。这不是相移不够，是【刻度没取一致】。
  现在两边都取 ×120（64+32+16+8，移位相加不占 DSP）：±120 像素，屏高 240
  正好顶到边，**圆就是圆**。（想整体缩一圈就把两个 120 一起改小。）

二、硬约束：只喂显示，可听输出逐位不变
------------------------------------------------------------------------
移相器【只读】sample_vol，输出【只写】wave_send_py 这一个寄存器；
sample_vol / s_dly / rvb_mix / DAC / I2S 没有任何一条回边读它 —— 纯 sink。
自检脚本第 [6] 节把这条做成了自动核对：ph_*/PH_A 无越界、送 DAC/I2S 的语句里
没有任何移相器信号、wave_send_py 在 top.v 只出现 4 处 / lcd_master.v 2 处。
★ 频谱/波形两屏的状态机、常数、刷新节奏【一行未动】（liss_on=0 时新寄存器原地不动）。

五、上板子看什么
------------------------------------------------------------------------
按键 3 按到第 3 档（李萨如·相位）：
  · **中音区（300Hz 附近）弹单音 → 应该是个圆**（这次刻度对齐了，不是椭圆）
  · 低音/高音 → 扁一点的环（一级全通的固有代价，不会是直线）
  · 按下「谐波」→ 图形会变形；和弦 → 多环叠加的花
  · 第 2 档（李萨如·干声×效果后）保持原样：不开效果是一条对角线，
    开延迟/混响/合唱后张开成环或螺旋 —— 那一档是"效果器示波器"
★ 观感（圆够不够圆、余辉长短、切档那 0.3s 淡出）只能你上板看；
  想调：余辉 LISS_DECAY_DIV、亮度、十字位置、刻度 120 都在 lcd_master.v 顶部。
