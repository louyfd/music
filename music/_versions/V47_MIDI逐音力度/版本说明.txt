1. 目的
--------------------------------------------------------
用户要对 MIDI 加【力度】解析，先听效果再决定后续。
★ 这是【试听版】：
  · 用调试版引脚约束（music.cst），不是实装版
  · 力度只做【逐事件】，不是逐音（同一个和弦里的音共用一个力度）

★ 电容触摸（TTP229）只有二值输出，硬件上测不到"真力度"，
  所以手弹那条路的力度【这次没做】。这次做的是【MIDI 播放】那条路：
  曲谱文件里本来就带 velocity，走蓝牙传下来就是真的逐音力度。

--------------------------------------------------------
2. 协议（定稿）
--------------------------------------------------------
    上位机 -> FPGA：  0xC3 + 1 字节 VEL（0~127）
    · 语义：只作用于【紧接着的下一个事件】，用完即清回 127
    · ★★ 不发 0xC3 时全程 127 = 满幅 ⇒ 老帧行为【逐字节不变】
    · >127 夹到 127（★ 不能简单截低位：200 截成 72 会把"很响"变"很小声"）
    · 上位机有「MIDI 力度」开关（默认开）；关掉就一个 0xC3 都不发
      —— 这就是给用户 A/B 对比用的

--------------------------------------------------------
3. FPGA 侧实现（全在 V47 新增，不动已有逻辑）
--------------------------------------------------------
uart_packet_echo.v：
    · VEL_BYTE=0xC3 / VEL_FULL=127 常量
    · ★ 力度用【两个寄存器】：vel_hold（等着的）-> pend_vel（挂到事件上的）
      ★★ 为什么不能只有一个：0xC3 的操作数【先】到、事件字节【后】到，
         只有一个寄存器的话，事件那一拍会把刚设的力度清成 127 当场丢掉。
         （和 oct_hold -> pend_oct 完全同一个套路）
    · reg [6:0] slot_vel [0:1023] —— 逐事件力度存储
      ★ 和 slot_mask/slot_dur 一样【单读单写】：写只有 wr_slots 那一处，
        读只有 rd_slot。破例就会掉出 BSRAM（坑 27 那一串教训）
    · vel_wait 已加进 op_wait / any_op_wait / 复位 / 中止清空 四个集合
      （漏一个就会出现"操作数被当成音符"或"卡住不超时"）
    · 输出 midi_vel：gate ? slot_vel_cur : 127
      ★★ gate=0 时给【满幅 127】而不是 0 ★★ ——
         给 0 的话音与音之间缩放系数会掉下去、下个音再爬上来，
         ramp 每采样点走 1，大落差要好几毫秒，反而弄出新"噗"声。

top.v：
    · midi_vel 两级同步到 clk_audio（准静态信号，和 midi_octs 同性质）
    · ★ 两条 wire（midi_vel / midi_vel_aud）必须【提前声明】——
      混音缩放那一段（voice_scale 附近）就要用，而驱动它的同步器在后面。
      不提前声明就是"先用后声明"，工具会建出隐式 1 位线。
      （这个坑本工程踩过三次了）
    · 缩放：
        voice_scale_val = voice_scale(n_voice)
        vel_bypass      = (vel_gain == 127)
        scale_tgt       = vel_bypass ? voice_scale_val
                                     : ((voice_scale_val * vel_gain) >> 7)
      ★ 满幅【完全旁路】，逐位等于 V46 —— 没发力度的曲子和老帧行为不变。
      ★ 力度只改【混音总缩放】，所以顺着 mix_scale_r 那条斜坡走，不会有台阶
        （V38 治"起音噗声"用的就是这条斜坡）。
      ★ 力度和"声部数避让"是【相乘】关系，互不干扰。

上位机（由子代理实施）：
    fpga_proto.py    VEL_BYTE / _OP_LEN[0xC3]=1 / clamp_vel / pack_vel /
                     Event.vel / 编码时在事件最前面写 [0xC3][VEL]（127 不写）
    fpga_midi.py     midi_to_frame(..., use_velocity=True)；
                     每格力度 = 该格所有音 velocity 的【最大值】；休止格不带
    spp_assistant.py 新增独立一行「MIDI 力度」勾选框 + 状态小字，默认开
    selftest.py      新增 GUI 级用例
