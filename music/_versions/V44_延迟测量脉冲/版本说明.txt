V44.2  延迟测量：保证「按一次键，各自只出一个脉冲」
========================================================
归档时间：2026-10-09
基线    ：V44.1（延迟测量首版，C19/C18 两个脉冲输出）
本次改动：只改 top.v 里的延迟测量块，不动任何已有功能

--------------------------------------------------------
一、为什么要改（用户提出的两个问题，都成立）
--------------------------------------------------------
用户问：「只发一个脉冲？真的吗，不会短时间连续几个吗，能让脉冲更明显吗」
查下来，两个怀疑都对：

【问题 1】lat_pcm（C18）原来会疯狂出脉冲 ★这是真 bug★
    原判据：lat_sound = (i2s_load != 32'd0) || (i2s_load_r != 32'd0)
    但 i2s_load 是【当前这一帧的瞬时样本值】。声音是波形，
    【每个周期要过零两次】→ lat_sound 跟着 0/1/0/1 跳
    → lat_pcm 会按过零率出脉冲，根本不是「一个音一个」。

【问题 2】lat_key（C19）只靠 10µs 的 holdoff 挡不住
    holdoff 结束后，键状态若再跳一次（指抖 / 坏读数 /
    和弦里几个键分几次扫描到），就还会再打一个脉冲。

【问题 3】脉冲太窄，示波器上看不清
    原来是 1µs。

--------------------------------------------------------
二、改法（三个都在 top.v 的延迟测量块里）
--------------------------------------------------------

1) lat_pcm 改成「按键武装 + 一次性」
     按键事件（音频域 key_new）→ lat_armed = 1     // 武装
     lat_pcm 发出            → lat_armed = 0     // 用掉就撤
     wire lat_pcm_evt = lat_armed & lat_sound & ~lat_sound_d;
   → 按一次键，最多出【一个】T2 脉冲，过零不再产生额外脉冲。

2) lat_key 改成「按住期间锁死」
     wire lat_evt_raw = |(lat_keys & ~lat_keys_d);
     按下（lat_evt_raw）  → lat_busy = 1          // 锁住
     所有键都松手（lat_keys == 0）→ lat_busy = 0  // 解锁
     wire lat_evt = lat_evt_raw & ~lat_busy;
   → 「按下…松手」一个完整周期 = 恰好一个 T1 脉冲，与 holdoff 无关。
   注：lat_keys 取自 ttp229_reader 的 key_stable（2/2 去抖输出），
       不是原始扫描值，所以抖动本身已经被滤过一道。

3) 脉冲加宽 1µs → 10µs
     LAT_HOLD_50M : 10'd499 （500 拍 × 20ns  = 10µs）
     LAT_HOLD_AUD : 8'd124  （125 拍 × 80ns  = 10µs）
   ★ 上限是【被测量间隔】：T1→T2 只有一个音频帧 ≈20.5µs，
     脉冲比间隔还宽就会糊在一起量不出来，所以取半个帧。
   ★ 慢时基（20ms/div）下 10µs 只有 0.05 格，仍然看不见形状 ——
     慢时基只用来【找事件】，量精确间隔请放大到 10~50µs/div
     或用延迟扫描（delayed sweep）。

四、只有板子能验的（本次归档时未上板）
--------------------------------------------------------
1. 用示波器确认：按一次键，CH1(C19) 与 CH2(C18) 各自【只有一个脉冲】。
   特别要试：
     · 单键轻按、重按、长按
     · 和弦（几个键一起按）
     · 连续快速弹
2. 量三个时间：
     T1 = 触摸 → C19 上升沿          （含 TTP229 扫描 + 去抖，ms 级）
     T2 = C19 上升沿 → C18 上升沿    （跨域 + 映射 + 起音 + 装载，约 20~25µs）
     T3 = C19 上升沿 → lck(A16)      （≈1 帧 20.5µs + DAC）
   注意：不是每个音都能量到 T2 —— 如果按键那一刻【已经在响】
   （上一个音还在延音 / 混响 / 延迟尾巴上），lat_armed 会武装但
   等不到「静音→有声」的沿，CH2 就不出脉冲。这是有意的：
   宁可量不到，也不能报一个错的位置。请从安静状态起弹。
