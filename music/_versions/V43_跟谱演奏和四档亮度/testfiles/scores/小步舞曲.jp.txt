# ── 本版相对原始转写只动了 6 处记号（其余一字未改）──────────────────
#  第15小节  2 3/ 2/ 1./ 7/      ->  2 3/ 2/ 1./ 7//      (3.25 -> 3 拍)
#  第20小节  #4 3/ 4/ 2/        ->  #4 3/ 4/ 2           (2.5  -> 3 拍)
#  第21小节  2 3 #4/ 5/ 6/ 7/   ->  2/ 3/ #4/ 5/ 6/ 7/   (4.0  -> 3 拍)
#  第25小节  5 1./ 7/ 1         ->  5 1./ 7// 1          (3.25 -> 3 拍)
#  第26小节  6 1./ 7/ 1         ->  6 1./ 7// 1          (3.25 -> 3 拍)
#  第28小节  2 1 7./1 2         ->  2 1/ 7/ 1/ 2/        (4.75 -> 3 拍)
#
# ── 改动依据 ────────────────────────────────────────────────────────
#  15/25/26：都是 X./ （附点八分音符）。简谱里"附点八分 + 十六分"是固定搭配，
#            后半那个音必须是 Y//（两条下划线）。原文漏了一条下划线。
#            改成 X./ Y// 后 0.75+0.25 = 1 拍，三处同时对上。
#  21：#4 之后是上行音阶跑句（2 3 #4 5 6 7），6 个音在 3/4 里就是 6 个八分。
#  20：#4 3 4 2 是 4 个音，必须是 6 个八分（=3 拍）。取"四分 + 两个八分 + 四分"：
#      #4 是 D 的升导音、用四分强调；中间 3 4 是快速经过音；末尾 2 用四分
#      引出下一小节的 2 3 #4 5 6 7 上行跑句。
#  28：2 1 7 1 2 共 5 个音，取本曲出现 8 次以上的招牌节奏"四分 + 四个八分"，
#      即 2 + 1/ 7/ 1/ 2/。原始转写里的 7. 应为 7/。
#
# ★ 20 / 28 这两处是【音乐性判断】，不是算出来的（4 个音凑 3 拍有多种解）。
#   上板听过之后如果不顺，直接改这两处记号即可，校验器会立刻告诉你对不对。
